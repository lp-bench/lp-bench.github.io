# proof-bench.github.io

The ProofBench website, served by GitHub Pages at https://proof-bench.github.io.
Plain HTML, CSS and JavaScript; no build step. Open `index.html` locally to preview.

* `assets/js/config.js`: everything that changes on launch day (`released`, arXiv id,
  repositories, leaderboard rows, contact).
* `assets/js/problem-data.js`: problem list, generated from proofbench-statements;
  do not edit by hand.
