Ten Challenges

Ten famous open problems in combinatorics, each turned into an infinite ladder of special cases and formalized in Lean 4. Every challenge carries a parameter r: proving a case that nobody has proved before earns a place on the leaderboard, and proving or refuting the conjecture for every r settles it.

Take part

  1. Start from the challenge files in TenChallenges/ten-challenges and write your proof in the Submission/ folder.
  2. Put the main result in Submission/Main.lean, inside namespace Submission, as theorem challenge_N for the value of r you are claiming. Helper files go next to it as Submission/<Name>.lean.
  3. Push your work to a GitHub repository you own. Public repositories work as they are. For a private one, install the ten-challenges-bot GitHub App on that repository only, with read access to its contents.
  4. Fill in one of the forms below. It opens a pre-filled GitHub issue in which you add the URL of your repository.

Proofs must compile without errors and without any sorry. So that accepted proofs keep working as Lean and Mathlib evolve, the form asks for permission to maintain compatible copies of your code. See the maintenance policy.
